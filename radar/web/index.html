安装到 Windows 桌面

用 Microsoft Edge 打开本站，在右上角「…」菜单中选择「应用」→「将此站点作为应用安装」。安装后可固定到桌面或任务栏，使用独立窗口阅读。

如果已经安装，可直接通过 Windows 开始菜单打开「期刊雷达」。
摘要翻译

使用 MyMemory 免费在线翻译，将英文摘要发送给翻译服务；译文缓存在当前浏览器，保留英文原文对照。机器翻译仅供阅读参考。

匿名免费额度约 5,000 字符/天，通常只够几篇长摘要。不会自动翻译全部历史文章。超额或服务不可用时保留原文；已缓存译文不消耗额度。

关闭自动翻译后，仍可在文章中点击“翻译摘要”。没有摘要的文章无法生成译文。
