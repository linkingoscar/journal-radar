      选择阅读方式

      用 Microsoft Edge 打开本站，在右上角「…」菜单中选择「应用」→「将此站点作为应用安装」。安装后可固定到桌面或任务栏，使用独立窗口阅读。

      上面的安装方式保存的是网页阅读版。需要往期目录或摘要补采时，请使用已安装的 Windows「期刊雷达」本机版快捷方式。

      两种版本的阅读记录分别保存；换版本前导出完整备份，再在目标版本导入。
      摘要翻译

      使用 MyMemory 免费在线翻译，将英文摘要发送给翻译服务；译文缓存在本机，保留英文原文对照。

      邮箱只保存在当前浏览器，翻译时会随英文摘要发送给 MyMemory，用于服务联系；不会写入公开仓库或阅读记录备份。桌面版与网页版需分别设置。

      有效邮箱版约 50,000 字符/天；留空时匿名版约 5,000 字符/天。本机按近 24 小时保守限制请求量，实际可用额度以服务返回为准。更换或移除邮箱不重置用量，已有缓存继续复用。

      关闭自动翻译后，仍可手动点击“翻译摘要”。缺少摘要时无法翻译。机器翻译仅供阅读参考；超额或服务不可用时保留原文。
